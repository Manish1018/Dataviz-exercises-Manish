# Netflix Movies & TV Shows Dashboard

## Project Overview

This project is an interactive Streamlit dashboard created for the Data Visualization course.

The dashboard analyzes the Netflix Movies and TV Shows dataset using Python, Pandas, Plotly, and Streamlit.

## Features

- Interactive Dashboard
- KPI Cards
- Sidebar Filters
- Movies vs TV Shows
- Netflix Growth Over Years
- Top Countries
- Top Genres
- Content Ratings
- Monthly Content Added
- Top Directors

## Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.
